## 1. 개인정보를 처리하는 목적

서비스는 다음 목적으로만 개인정보를 처리하며, 목적이 바뀌면 미리 알리고 필요한 경우 다시 동의를 받습니다.

1. **회원 가입·로그인과 계정 관리** — 본인 확인, 여러 기기 간 기록 동기화, 부정 이용 방지
2. **기록 서비스 제공** — 할일·메모·일기·습관·목표·일정·사진·연락처 등 이용자가 입력한 기록의 저장과 표시
3. **커뮤니티 기능** — 커뮤니티·챌린지·채팅·게시판·순위표에서 다른 이용자와 함께 쓰는 기능
4. **알림** — 이용자가 켠 경우 휴대폰 알림·텔레그램 메시지 발송
5. **AI 기능** — 이용자가 버튼을 눌렀을 때만 메모 정리, 일기 만들기, 운세, 잔고 캡처 읽기 등
6. **문의 응대와 서비스 개선** — 문의·제안 처리, 앱 오류 확인

## 2. 처리하는 개인정보 항목

### 가. 가입·로그인 때 (필수)
- 구글 계정의 **이메일 주소, 이름(표시 이름), 프로필 사진 주소**, 서비스 계정 고유번호
- 마지막 접속 시각

### 나. 이용자가 직접 입력·선택한 경우 (선택)
| 기능 | 항목 |
|---|---|
| 기록 | 할일, 메모, 일기, 습관, 목표, 일정, 첨부 사진, 첨부 파일 링크 |
| 내 사람들 | **이용자가 고른 다른 사람의** 이름·전화번호·회사·직책·생일·기념일·메모·명함 사진 |
| 운세 | 생년월일, 태어난 시간 |
| 보유자산·구독 | 보유 종목·수량·평균단가·현금, 구독 서비스 이름·금액·결제수단 별명(카드번호는 받지 않음), 잔고 캡처 사진(읽기만 하고 저장하지 않음) |
| 커뮤니티·소셜 | 닉네임, 작성한 글·댓글·채팅·사진, 출석·인증 기록, 순위표의 점수·칭호 |
| 수험생 모드 | 시험 D-day, 공부 시간, 오답 노트(문제 사진 포함) |
| 텔레그램 연결 | 텔레그램 봇 정보, 대화방 번호 |
| 구글 캘린더·드라이브 연결 | 연결 권한(이 앱이 만든 파일·일정에만 접근), 일정·파일 이름과 링크 |
| 문의·제안 | 문의 내용, 가린 이메일 |
| 날씨 | 이용자가 정한 도시 이름 |
| 🔶 영토(위치) — *공개할 때만* | 기능을 쓸 때 기기의 현재 위치를 받아 **행정동(읍·면·동)만 판정하고 좌표는 저장하지 않음**. 차지한 행정동 기록 |

### 다. 서비스 이용 중 자동으로 생기는 정보
- 휴대폰 알림을 켠 경우 알림 수신 주소(브라우저가 만든 값)
- 앱 오류 기록: 오류 내용·발생 화면·앱 버전·기기 종류 (**메모·일기 등 이용자 기록은 넣지 않음**)
- 기기 저장소(브라우저 localStorage·IndexedDB)에 저장되는 설정·기록 사본

## 3. 보유·이용 기간

- 회원 정보와 기록은 **회원 탈퇴(계정 삭제) 때까지** 보관하고, 탈퇴하면 지체 없이 파기합니다. 🔶 *계정 삭제 기능은 아직 없음 — 공개 전 만들어야 함*
- 휴지통으로 옮긴 메모는 30일 뒤 자동으로 지워집니다.
- 앱 오류 기록은 30일 뒤 지워집니다.
- 텔레그램 연결 코드는 만든 뒤 10분만 쓸 수 있습니다.
- 법령에 따라 보관해야 하는 경우 그 기간 동안 보관합니다.

## 4. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 이용자가 미리 동의한 경우나 법령에 특별한 규정이 있는 경우는 예외로 합니다.

- 커뮤니티·챌린지에 쓴 글·닉네임은 **그 커뮤니티 멤버 또는 로그인한 다른 이용자에게 보이며**, 이는 이용자가 공개를 선택한 것입니다.
- 순위표에는 닉네임·점수·칭호만 보이고 이메일은 보이지 않습니다.

- 구글 캘린더·드라이브는 **이용자 본인의 구글 계정**에 저장되며, 운영자가 보관하지 않습니다.

## 6. 개인정보 파기

- 보유 기간이 끝나거나 목적을 이루면 지체 없이 파기합니다.
- 전자 파일은 복구할 수 없는 방법으로 지웁니다.

## 7. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보를 **열람·정정·삭제·처리정지**하도록 요구할 수 있습니다.

- 대부분의 기록은 앱에서 직접 보고, 고치고, 지울 수 있습니다.
- 계정 삭제: 🔶 [앱 설정 → 계정 삭제] *(만들 예정)*
- 그 밖의 요청: 아래 문의처로 연락하면 지체 없이 처리합니다.

## 8. 만 14세 미만 아동

서비스는 **만 14세 이상만 가입할 수 있습니다.** 처음 로그인할 때 만 14세 이상인지 확인하며, 만 14세 미만으로 확인되면 가입을 받지 않고 그 정보는 바로 파기합니다.

## 9. 자동 수집 장치

- 서비스는 로그인 유지와 설정 저장을 위해 브라우저 저장소(localStorage·IndexedDB)와 로그인 쿠키를 씁니다.
- 브라우저 설정에서 지울 수 있으나, 지우면 이 기기에만 있던 설정이 사라지고 다시 로그인해야 할 수 있습니다.
- 광고·추적용 쿠키는 쓰지 않습니다.

## 10. 안전성 확보 조치

- 모든 통신은 암호화(HTTPS)합니다.
- 데이터 접근은 보안 규칙으로 **본인 기록은 본인만**, 커뮤니티 내용은 멤버만 보도록 제한합니다.
- 메모 잠금을 켠 메모는 이용자 비밀번호로 **암호화**해 저장하며, 운영자도 열 수 없습니다.
- 앱 잠금 비밀번호는 원문을 저장하지 않습니다.
- 운영자는 문의 처리·신고 대응·법령 준수 등 운영에 필요한 경우에만 관리자 권한으로 기록에 접근합니다. 🔶 *관리자가 볼 수 있는 범위(가입 이메일, 문의, 커뮤니티 채팅·게시글 등)를 이렇게 알릴지 확인 — 예전에 채팅방 안내에는 "운영자가 볼 수 있다"는 표현을 넣지 않기로 했지만, 처리방침에는 정확히 적는 것이 안전*
