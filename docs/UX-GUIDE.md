# DayMate UX/UI 가이드

새 칸·화면을 만들거나 기존 화면을 올릴 때 먼저 읽는다. 사용자가 확정한 것을 기본으로 하고, 근거는 CLAUDE.md의 해당 장에 있다. **확정되지 않은 값·규칙은 `(제안)`으로 표시했다.** 새로 확정되는 화면 원칙은 여기와 `src/styles.js`의 `UI`에 함께 반영한다(CLAUDE.md에는 한 줄 + 이 문서 링크).

값의 원본은 `src/styles.js`의 `UI`다. 숫자를 화면 파일에 직접 쓰지 말고 이 값을 쓴다.

---

## 0. 전제

- **큰 글씨가 기본값이다.** 글씨 크기가 `large`(기본)이면 `.dm-phone`에 CSS `zoom: 1.1`이 걸려 아래 px는 화면에서 1.1배로 보인다. PC 대시보드는 창 폭 1500px 이상에서 칸에 1.1이 더 곱해진다(1.21배). 전체 크기는 `font-size`로 일괄 조정하지 않고 `zoom`을 쓴다(CLAUDE.md 8).
- (제안) **확인 기준 폭은 휴대폰 360~412px.** 새 칸은 360px에서 가로로 넘치지 않아야 한다.
- **PC 대시보드는 기존 화면을 그대로 넣는 틀이다.** 오늘 탭·주간 일정을 고치면 대시보드 안에서도 바뀐다. 대시보드용으로 복사하지 않는다(CLAUDE.md 14.7).
- **새 디자인은 스위치 하나**(설정 → 앱 관리 "새 디자인")로 켜고 끈다. 예전 화면 코드는 사용자가 확정할 때까지 지우지 않고 `newLook ? 새 : 예전`으로 둔다.
- **달력 탭은 새 디자인에서 제외**다(사용자가 "원래 것이 좋다"고 되돌림). 다시 바꾸자고 하지 않는다.

## 1. 간격

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `gutter` | 16 | 화면 좌우 바깥 여백 |
| `box.pad` / `box.radius` / `box.gap` | 14 / 20 / 12 | 둥근 칸(`boxCard`): 안쪽 여백·모서리·칸 사이 |
| `titleGap` | 16 | **칸 제목 아래 여백.** 제목 바로 밑에 내용을 붙이지 않는다(2026-11-07 지적) |
| `headingGap` | 14 | `SectionHeading`(My 탭 계열) 제목 아래 |
| `controlGap` | 14 | 제목 줄 아래 한 줄짜리 조작부(‹ 날짜 › 등) 앞에 더 두는 여백 |
| `rowGap` | 10 | 목록 줄 사이 |
| `rowGapDense` | 5 | 빽빽하게 보여 주는 곳(PC 대시보드 이번 주 할일) |
| `rowPadY` | 10 | 구분선 있는 줄의 위아래 안쪽 여백 |

- **접힌 칸**은 제목 아래 여백을 뺀다(`foldPad`).
- 접기 버튼과 조작 버튼이 맞닿으면 깨져 보인다(주간 일정, 2026-11-07) — `controlGap`을 쓴다.
- 칸 **안에 칸을 넣지 않는다.** 처음 안내·오늘 계획 같은 카드는 칸 위에 따로 둔다(CLAUDE.md 14.7).
- 둥근 칸은 `S.card`가 아니라 **`boxCard`**를 쓴다. `S.card`의 backdropFilter·zIndex는 칸 안의 fixed 창을 가둔다.
- 칸 접기는 오른쪽 끝 **`FoldButton`** 하나로 한다.
- 오늘 탭은 페이지 전체가 스크롤되므로 위에 붙는 띠는 sticky가 아니라 **fixed**로 만든다.

## 2. 글씨

- **칸 제목은 19px 굵게 + 색 배지 아이콘 (2026-11-07 사용자 확정, 비교 화면에서 고름).** 글씨를 키우며 본문(그때 할일 줄 17px, 2026-11-09부터 16px)과 제목이 같은 크기가 돼 제목이 눈에 안 띄었다. 그래서 제목은 `UI.title`(19), 아이콘은 `<SectionIcon name=… size={20} badge />` — **2026-11-09부터 동그라미 바탕 없이 칸마다 색 선 아이콘**(`BADGE` 색, 사용자가 시안에서 고름 — 11-08의 색 꽉 찬 동그라미는 칸마다 색 점이 많아 알록달록했다). 새 칸은 공통 `SectionHeading`(배지 포함)이나 오늘 탭 `secTitle`·`secIcon`을 쓰면 자동으로 맞는다. 칸마다 아이콘 색이 정해져 있다(`TodayLook.jsx` `COLORS`). 섹션 제목은 본문보다 작게 하지 않는다(2026-10-30).
- **좁은 폭(360px)에서 제목 줄이 넘치지 않게:** 제목 글자는 한 줄 고정(`whiteSpace: nowrap`), 개수 같은 덧붙임은 작은 회색 글씨, 안내 문구는 말줄임. 오른쪽 버튼이 많은 줄(오늘의 할일)은 자리가 모자라면 버튼 묶음이 아랫줄 오른쪽으로 내려간다(`flexWrap` + `marginLeft: auto`). 음각·그림자 글자는 대비를 낮춰 쓰지 않는다.
- 보조 글씨는 **13px 이상**(`sub`, CLAUDE.md 14.7). 흐린 버튼·작은 글씨는 또렷하게. 아직 못 옮긴 곳은 7장에 적었다.
- **글자 크기 5단계 (2026-11-09 사용자 확정 — 화면 제목이 칸 제목보다, 묶음 이름이 항목보다 작은 곳이 많았다).** 값은 `styles.js` `UI`:
  | 단계 | 값 | 쓰는 곳 |
  |---|---|---|
  | 화면 제목 `pageTitle` | 22px 굵게 | 맨 위 My·설정·커뮤니티… — `S.title`에 `className="dm-page-title"`를 달면 `index.css`가 새 디자인에서 22px로 (오늘 탭 인사는 24px) |
  | 칸 제목 `title` | 19px 굵게 | 둥근 칸 제목, 설정 목록 머리(`MenuGroup`), 통계·배틀 소제목 |
  | 묶음 이름 `group` | 17px 굵게 | 칸 안 묶음(인생목표·올해 목표) |
  | 목록 항목 `item` | 16px 보통 | 할일(지금 할 일 18px)·습관·언젠가할일·주간 일정·목표 항목·다가오는 날 |
  | 보조 `sub` | 13~14px | 날짜·설명·개수·버튼 |
  - **위 단계가 아래 단계보다 작으면 안 된다.** 새 칸·새 화면을 만들 때 이 표에서 고른다. 큰 숫자(점수·금액)만 예외.
  - 작은 글씨가 많은 화면은 상자에 `className="dm-min13"`을 달면 새 디자인에서 9~12px가 13px가 된다(배틀).
  - 주간 일정(새 디자인 오늘 탭)은 날짜를 **"9(월)" 한 줄**(토 파랑·일 빨강), 할일 16px, 빈 날 14px. 달력 탭은 예전 모양(`roomy` 없음).
- 긴 제목은 **띄어쓰기 없이도** 화면을 넘지 않아야 한다: `wordBreak: 'keep-all'` + `overflowWrap: 'anywhere'`, 한 줄 목록은 말줄임. 그리드 안에서는 `minmax(0, 1fr)`(2026-11-07, 주간 일정이 가로로 넘친 원인).

## 3. 색

- **밝은 화면·어두운 화면 둘 다에서 확인한다.** 어두운 화면용 연한 색(`#C9D7FF`·`#c4b5fd`·`#b8c3ff`)을 밝은 화면 버튼에 쓰지 않는다.
- **글꼴은 Pretendard, 새 디자인 굵기는 한 단계 가볍게 (2026-11-09 사용자 선택, 삼성 나우 브리프 참고).** 글꼴은 `index.html`이 불러오는 Pretendard Variable(앱 `:root`·`S.app`). 제목에 영문 글꼴(Plus Jakarta Sans)을 따로 지정하지 않는다 — 한글이 없어 제목 한글만 기기 글꼴로 나왔다. 굵기는 화면 코드의 값을 그대로 두고 `index.css` `[data-look="new"]`에서 900·800→600, 700→500으로 낮추되, 900인 제목은 18~23px→700, 24px 이상→800으로 남긴다(인라인 style 글자로 찾으므로 `fontWeight`를 숫자로 쓴다). **달력 탭은 `.dm-keep-look`으로 빼서 예전 굵기.** 새 칸을 만들 때 제목은 900, 강조 글씨는 800, 보통 굵게는 700으로 쓰면 새 디자인에서 자동으로 한 단계 가벼워진다.
- **새 디자인 색은 D안 — 아이폰 미리알림·설정 방식 (2026-11-08 사용자 선택, 비교 화면에서 고름).** 어두운 화면 검정 `#000` 바탕 + `#1C1C1E` 칸, 밝은 화면 `#F2F2F7` 바탕 + 흰 칸. 칸은 테두리·그림자 없이 밝기 차이로만 나누고, 어두운 화면 번짐(`dm-blob`)은 숨긴다. 강조색은 파랑 하나(`#0A84FF`/`#007AFF`). 칸 제목 아이콘은 **바탕 없는 색 선 아이콘**(`TodayLook.jsx` `BADGE`, 2026-11-09 변경 — 예전 색 꽉 찬 동그라미). 값은 모두 `index.css`의 `[data-look="new"]` 한 곳이고, `html`의 `data-look`은 새 디자인 스위치를 따른다(`todayLook.js`).
- **강조색은 `var(--dm-accent, 예전색)`으로 쓴다.** 연한 바탕은 `var(--dm-accent-soft, 예전 rgba)`, 강조 테두리는 `var(--dm-accent-line, 예전 rgba)`(새 디자인에서는 투명), 큰 버튼 바탕은 `--dm-btn-bg`, 칸 테두리·그림자는 `--dm-card-line`·`--dm-card-shadow`. 이 변수들은 새 디자인에서만 정의되므로 예전 디자인은 괄호 안 예전 색 그대로다 — 그래서 `newLook ? :` 분기 없이 한 줄로 쓴다. 2026-11-08에 예전 파랑 619곳을 이렇게 바꿨고 예전 디자인 화면은 픽셀 비교로 같았다. **주의:** `${color}22`처럼 글자를 이어 붙여 투명도를 만드는 곳(`smallBtn`·`chipBtn` 등)에는 변수를 넣으면 깨진다 — 그런 곳은 헥스 그대로 둔다. 배틀 화면의 편 색(파랑·빨강)도 그대로.
- 예전 디자인 강조색은 양쪽에서 보이는 `accent`(`#5B7CFA`)·`accent2`(`#8B5CF6`).
- **차트 색은 `index.css`의 `--dm-viz-1~4`**(밝은·어두운 화면 각각 따로 고르고 색약 구분·대비를 검증한 값, 2026-11-07). 순서대로 쓰고 다시 섞지 않는다(색은 항목을 따라간다). 밝은 화면에서 3·4번은 대비가 낮아 **차트 옆에 이름·값을 늘 글자로** 함께 둔다. 글자는 차트 색이 아니라 글자색 변수로 쓴다. 부품: `components/PortfolioCharts.jsx`.
- (제안) 글자·배경은 되도록 `var(--dm-text)`·`var(--dm-sub)`·`var(--dm-muted)`·`var(--dm-card)` 등 테마 변수를 쓴다. 기존 코드에는 색 값을 직접 쓴 곳이 많다.

## 4. 버튼·누르는 칸

- 전역 `button`에 좌우 padding 1.2em이 있다. **크기를 지정하면 `padding: 0`을 함께 쓴다.**
- **새로 만드는 버튼의 누르는 칸은 40px 이상**(`touch`, 2026-11-07 사용자 확정). 그림이 작아도 칸은 40으로 잡는다. 작은 버튼은 그림·배치를 그대로 두고 `className="dm-hit"`로 칸만 넓힌다(주변 버튼과 8px 이상 떨어져 있을 때). 옆으로만 좁으면 `dm-hit-y`(세로만), 위아래로만 좁으면 `dm-hit-x`(가로만). 기존의 더 작은 버튼은 탭별로 올릴 때 키운다(7장).
- (제안) 칩·보조 버튼 높이 34(`chip`).
- **부가 버튼(순서 바꾸기 등)은 자리가 있으면 제목 줄 오른쪽에** 둔다. 제목 줄이 이미 차 있으면 목록 아래에 둔다(오늘의 할일, 2026-11-07 사용자 확정).
- **버튼 테두리는 키보드로 옮겨 갈 때만** 보인다(`:focus-visible`). 터치·클릭한 버튼에 남으면 화면이 깨져 보인다(2026-11-07).
- 떠 있는 ＋ 버튼, 홈 화면 위젯은 만들지 않는다(CLAUDE.md 14.7·14.6).

## 5. 화면 구조

- **목록은 보기 전용, 편집은 상세 창**이다. 목록에서 바로 하는 것은 체크·언젠가·✕뿐(CLAUDE.md 14.1).
- **지우기·옮기기는 확인창 대신 5초 되돌리기**(`useUndo`). 완료 체크도 오늘 탭·달력 미리보기·자세히보기에서 5초 되돌리기가 뜬다. **확인창을 유지하는 것:** 구글 캘린더와 연결된 할일, 서버에서 바로 지워지는 것(게시글·댓글·채팅·커뮤니티), 사진 파일 삭제, 연락처 삭제, 영구 삭제·초기화(CLAUDE.md 14.1).
- **순서 바꾸기는 편집 모드**(줄마다 ▲▼). 편집 중에는 체크를 막고 삭제·언젠가·지금 할 일 버튼을 숨기며, 줄을 눌러도 상세 창이 열리지 않는다. 끌어 옮기기·길게 누르기는 쓰지 않는다.
- **휴대폰에서는 화면을 열 때 입력칸에 자동으로 커서를 두지 않는다**(`canAutoFocus`, CLAUDE.md 14.7).
- 앱 위에 덮는 창(포털)은 앱의 알림이 가려지므로 자기 `<Toast>`를 따로 둔다(CLAUDE.md 15).
- 원화 금액은 소수점 없이, '일기토'는 '배틀'로 쓴다(CLAUDE.md 14.7).
- **새 창·덮개·하위 화면에는 `useBackClose`**를 붙인다(CLAUDE.md 15).
- **시트·팝업은 `.dm-phone`에 포털**로 그린다(아래 메뉴에 가려지지 않게).
- 사진 첨부 input에 `capture`를 넣지 않는다(CLAUDE.md 7).
- 저장 실패 같은 문제는 **문제 있을 때만** 띠로 알린다("저장됨"을 매번 띄우지 않는다).

## 6. 새 칸·화면 체크리스트

만들거나 고친 뒤 **직접 화면으로** 확인한다(코드만 보고 끝내지 않는다).

1. **360px 폭**에서 가로로 넘치지 않는다. 긴 제목(띄어쓰기 없는 것)·습관·할일 여러 개를 넣어 본다.
2. **큰 글씨**(zoom 1.1)에서 제목과 버튼이 겹치지 않는다.
3. **밝은 화면·어두운 화면** 둘 다 글자가 보인다.
4. 제목 바로 밑에 내용이 붙어 있지 않다(`titleGap`).
5. 접은 상태·펼친 상태, 내용이 없을 때(빈 상태)를 본다.
6. 새 창이면 뒤로가기가 그 창부터 닫는다.
7. 새 디자인 스위치를 끈 예전 화면도 그대로 나온다.
8. 새 설정을 만들었으면 `utils/settingsSearch.js`에 한 줄, 기기별 값이면 `accountSwap`의 기기 설정 목록에 추가한다. 오늘 탭의 새 칸이면 `TODAY_ORDER_SECTIONS`·`todaySections`에 넣는다.
9. 테스트: `npm run test:smoke`에 새 화면 추가, 기록 이동 관련이면 `test:data`.
10. 데이터가 많을 때를 본다(언젠가할일 20개 이상 등).
11. 오늘 탭·주간 일정을 고쳤으면 **PC 대시보드** 안에서도 본다(창 폭 1500px 이상 포함).
12. 글자 없는 버튼에 `aria-label`을 넣고, 흐린 글자가 배경과 구분되는지 본다.
13. 배포 뒤에는 **휴대폰 실기기**에서 본다. 앱을 완전히 닫았다 열어야 새 화면이 보일 수 있다(서비스워커). 못 봤으면 못 봤다고 보고한다.

## 7. 탭별 새 디자인 적용 현황

오늘 ✅ · My ✅ · 설정(첫 화면·하위 화면) ✅ · 내 사람들·보유자산·통계 작은 글씨 ✅ · 메모(쓰기 화면·목록·메모 관리자) ✅ · 소셜(커뮤니티·챌린지·자유게시판) ✅ · 달력 — 제외.

기준값(`UI`)으로의 이전은 오늘 탭부터 탭마다 차례로 하고, **두 가지로 나눈다.** ① 값이 안 바뀌는 치환: 전후 화면을 비교해 같은지 확인하고 진행한다. ② 값이 바뀌는 개선: 먼저 목록을 보여 드리고 확인받는다. 예전 화면(`newLook` 아닌 쪽) 값은 바꾸지 않는다. 기존 화면의 숫자를 한꺼번에 바꾸지 않는다.

**아직 기준에 못 미치는 곳 (2026-11-07 점검, ② 개선 대상):**

- 작은 글씨: 2026-11-07 달력 탭을 뺀 모든 측정 화면에서 13px로 맞췄다. 주간 일정은 오늘 탭·PC 대시보드만 `roomy`이고 **달력 탭은 예전 값 그대로**다. 그대로 두는 것: 아래 메뉴 글자 12, 숫자 뱃지, 동그라미 안 글자(? · 순서 번호 · 태그 ✕), 능력치 이모지 아이콘, 통계 그래프 날짜 8.
- 작은 버튼 — 일부러 40을 못 채운 곳: 오늘의 할일 제목 줄 📅 ‹ ›(간격이 좁아 세로만 40), 어제 못 한 일 ✕(세로만), 요일 동그라미 34×41(7개가 한 줄), 메모 쓰기 위쪽 아이콘(가로 33), 보유자산 📝✏️🗑(위아래로 붙어 가로만 40), 태그 숨기기 ✕ 16(칩과 겹쳐서 넓히지 않음). 남은 것: 메모 관리자 보기 모드의 #태그 45×24, 자유게시판 등록 38.
- 제목 아래 여백: 커뮤니티 칸 제목은 2026-11-11 `headingGap`(14)으로 맞춤.
- 색: 달력 탭 주간 일정의 오늘 요일 `#AFC0FF`(밝은 화면에서 흐림, 달력은 제외라 그대로). 대시보드는 2026-11-11 강조색으로.

- **대시보드 달력 일정 글자는 두 줄까지 줄바꿈**(대시보드에서만, 2026-11-11 — 1240 창에서 앞 몇 글자만 보였다).
